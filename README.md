# Alzheimer's Disease Detection Using Deep Learning

## Overview
This project explores deep-learning-based image classification for Alzheimer's disease detection using an eight-class classification setup. The project investigates how machine-learning and computer-vision techniques can be applied to medical imaging data.

## Objectives
- Explore multiclass image classification using deep learning.
- Prepare and process image data for model training.
- Train a model to classify images into eight predefined categories.
- Evaluate model performance using the metrics and results available in the notebook.
